All notable changes to this skill are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] — 2026-08-25

### Added
- Initial skill release
- Multi-pass workflow: Diagnose → Macro → Style → Grammar → Verify
- Coverage of journal articles, theses, grant proposals, conference abstracts, posters
- Bilingual (Chinese ↔ English) support in both directions
- Domain coverage: psychology / cognitive / neuroscience, STEM-medical, humanities / social sciences, general academic
- Style references:
  - `references/english-academic-conventions.md`
  - `references/common-en-errors.md`
  - `references/chinese-academic-conventions.md`
  - `references/common-cn-errors.md`
  - `references/translation-strategies.md`
- Worked examples:
  - `examples/journal-abstract-bilingual.md`
  - `examples/thesis-introduction-en.md`
  - `examples/grant-proposal-cn-en.md`
