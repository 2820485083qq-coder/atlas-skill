# 中文学术写作常见错误 + 中式英语模式

## 一、中文学术写作常见错误

### 1.1 病句类

| 错误 | 修正 | 说明 |
| ---- | ---- | ---- |
| 主语省略导致句意不清 | 补主语或重构 | 中文常省略主语，但学术写作要明确 |
| 搭配不当 | 重新选择动词 | 如"对...进行改进"应改为"改进..." |
| 成分残缺 | 补全 | 如"基于此，本文"后面应接完整谓语 |
| 句式杂糅 | 拆为两句 | 把两句话糅在一起 |

### 1.2 词汇类

| 口语 | 学术 | 说明 |
| ---- | ---- | ---- |
| 我们发现 | 本文发现 / 研究发现 | "我们"在学术写作中应明确主体 |
| 做了研究 | 开展了研究 / 进行了研究 | "做了"太口语 |
| 挺重要 | 具有重要意义 / 至关重要 | 程度词应精确 |
| 出现了问题 | 存在不足 / 存在偏差 | 中性描述 |
| 看一下 | 考察 / 审视 / 检验 | 动词学术化 |
| 弄清楚 | 阐明 / 厘清 / 揭示 | 动作精确化 |
| 用 | 采用 / 使用 / 运用 | 视语境选 |
| 等等 | 等 / 等多种 / 等等（适度） | 避免连续 5 个"等等" |

### 1.3 标点类

| 错误 | 修正 |
| ---- | ---- |
| 一段到底没有逗号 | 长句（>30 字）必有逗号断句 |
| "、"使用泛滥 | 并列分句用"，"而非"、" |
| 引号不规范 | 中文用""或'' |
| 中英混排标点混乱 | 中文正文用全角""，()；英文用半角"", () |

### 1.4 逻辑连接词

| 错误 | 修正 |
| ---- | ---- |
| 缺少过渡词 | 段落首句加"基于此"、"然而"、"此外"等 |
| 过渡词堆砌 | 避免"同时...然后...此外...因此...所以..."连用 |
| 转折词用错位置 | "但是"应在主语后或独立从句 |

## 二、中式英语 (Chinglish) 模式

这是中国学者写英文论文最常见的问题——把中文句式、词汇直接替换成英文。

### 2.1 高频 Chinglish 句式

| Chinglish | Native English |
| --------- | -------------- |
| "the research of X" | "research on / into X" |
| "study of the effect of X on Y" | "effect of X on Y" (verb form) 或 "study examining how X affects Y" |
| "with the development of society" | "as society has developed" / 删除 |
| "in our country, ..." | "in China, ..." (首次); 之后用代词或重组 |
| "play an important role in X" | "is central to X" / "shapes X" / "drives X" |
| "we take measures to..." | "we" + 具体动词 |
| "more and more studies" | "a growing body of research" / "increasingly, studies..." |
| "has a great significance" | "matters" / "is significant" |
| "is becoming more and more important" | "is becoming increasingly important" |
| "it is well known that" | 通常删除，直接说 |
| "as we all know" | 删除 |
| "in China, X is still in its early stage" | "in China, X remains underdeveloped" / 具体描述 |
| "according to our investigation" | "we found that..." (active) |
| "through the analysis of X, we found" | "analysis of X revealed" / "we analyzed X and found" |

### 2.2 Chinglish 用词

| Chinglish | Native |
| --------- | ------ |
| "very" + 形容词 | 删除 "very" 或用 "considerably" / "substantially" |
| "very important" | "important" / "critical" / "essential" |
| "make a research" | "conduct research" / "do research" / 直接用动词 study/investigate |
| "make an analysis" | "analyze" |
| "make a comparison" | "compare" |
| "make a decision" | "decide" |
| "give some suggestions" | "suggest" / "recommend" |
| "have a good effect" | "is effective" |
| "improve the quality" | "improve" (quality 隐含) |
| "in a certain extent" | "to some extent" / "to a certain degree" |
| "contact with" | "contact" (verb, no preposition) |
| "depend on" (在所有场合) | depend on (固定) / rely on (更口语) |
| "people's living standard" | "living standards" / "standard of living" |

### 2.3 Chinglish 标点

| 错误 | 修正 |
| ---- | ---- |
| "Mr." 后空格再句号 | "Mr." 后直接句号 |
| 中文逗号出现在英文段落 | 用半角逗号 |
| 中文括号出现在英文段落 | 用半角括号 |
| 连续 3 个以上句子无逗号 | 长句必加逗号 |

### 2.4 Chinglish 段落结构

**特征**：
- 段首无 topic sentence
- 长句堆叠
- "Firstly, secondly, thirdly" 模式
- 频繁使用 "in a word", "to sum up"
- 大段无段落切分

**修正**：
- 每段加 topic sentence
- 拆长句
- 用 "first / second / third" 或 "initially / subsequently / finally"
- 段落 200 字以内

### 2.5 中式英语检测清单

完成英文写作后，逐项检查：

- [ ] 是否每个段落首句都有 topic sentence？
- [ ] 长句（>25 词）是否有内部标点？
- [ ] 是否有"the research of X"模式？
- [ ] 是否在重复使用 "very / more and more / in our country"？
- [ ] 是否每个动词都是"make / do / give / have"？
- [ ] 中文章节译成英文时是否只是替换单词？
- [ ] 标点是否全部半角？
- [ ] 冠词 (a/an/the) 使用是否正确？
- [ ] 时态是否一致？
- [ ] 单复数是否一致？
- [ ] 主谓是否一致？

## 三、中文学术写作中的英文术语规范

| 场景 | 规范 |
| ---- | ---- |
| 首次出现英文术语 | 给出英文原文 + 缩写："认知行为疗法 (cognitive behavioral therapy, CBT)" |
| 之后单独使用 | 可单独使用任一语言 |
| 在英文段落 | 用英文原文 |
| 期刊名 | 斜体 + 缩写 |
| 缩写 | 首次定义后用大写（CBT, PHQ-9, MDD）|

## 四、典型问题句改造示例

### 示例 1：主语不明

❌ "通过对 X 的研究，发现了 Y 的作用。"

✅ "对 X 的研究表明，Y 在 Z 过程中发挥关键作用。"

### 示例 2：动词名词化

❌ "本文对 A 进行了分析，对 B 进行了讨论。"

✅ "本文分析了 A，讨论了 B。"

### 示例 3：被动语态堆砌

❌ "X 被认为是被 Y 所影响的。"

✅ "通常认为 X 受 Y 影响。"

### 示例 4：四字结构堆砌

❌ "本研究通过系统梳理、综合分析、深入探讨、实证研究的方法，对 X 进行了全面研究。"

✅ "本研究采用系统综述方法，分析了 X 的作用机制。"

### 示例 5：主观断言

❌ "显然，X 是导致 Y 的原因。"

✅ "本研究的结果提示，X 可能是 Y 的诱因之一。"

### 示例 6：模糊量词

❌ "很多研究表明 X 具有显著效果。"

✅ "现有 17 项随机对照试验表明 X 具有显著效果 (Cohen's d = 0.62, 95% CI [0.45, 0.79])。"

### 示例 7：英译中翻译腔

❌ "已经被许多研究所证明的是，X 在 Y 的治疗中是有效的。"

✅ "诸多研究表明，X 对 Y 具有显著疗效。"
