# English Academic Writing: Common Errors

This reference covers the most frequent errors in English academic writing — grammar, word choice, and structural issues. Use it as a verification checklist after polishing English text.

## 1. Articles (a / an / the / zero article)

The most common ESL error in English academic writing.

### 1.1 Generalization = zero article

| ❌ | ✅ |
| -- | -- |
| The depression is common. | Depression is common. |
| The serotonin modulates mood. | Serotonin modulates mood. |
| The CBT is effective. | CBT is effective. |

**Rule**: When making a general statement about a class of things, omit "the".

### 1.2 Specific reference = "the"

| ❌ | ✅ |
| -- | -- |
| We recruited 100 adolescents. Adolescents were aged 12–17. | We recruited 100 adolescents. **The** adolescents were aged 12–17. |

**Rule**: When referring back to a specific subset already introduced, use "the".

### 1.3 First mention, nonspecific = "a/an"

| ❌ | ✅ |
| -- | -- |
| We conducted study. | We conducted **a** study. |

### 1.4 Articles with academic terms

| Rule | Example |
| ---- | ------- |
| Diseases and disorders: zero article for class | "**Ø** Major depression is common." (specific case: "**The** major depression in this cohort...") |
| Methods/techniques: zero article | "We used **Ø** fMRI to measure..." |
| Specific instruments: "the" | "**The** PHQ-9 was administered..." |
| Geographic entities: varies | "in **Ø** China" (no article with country names unless "the United States", "the Netherlands") |

## 2. Prepositions

### 2.1 Common confusions

| ❌ | ✅ |
| -- | -- |
| discuss about | discuss |
| research about | research on / into |
| focus about | focus on |
| in the basis of | on the basis of |
| despite of | despite |
| according with | according to |
| in regards to | in regard to / with regard to / regarding |
| compare with (vs. compare to) | with = similar; to = different |

### 2.2 Verb + preposition (fixed collocations)

| Verb | Preposition | Example |
| ---- | ----------- | ------- |
| depend | on | "depend on the dosage" |
| consist | of | "consist of three parts" |
| result | in | "result in significant improvement" |
| correlate | with | "correlate with age" |
| associate | with | "associated with higher risk" |
| differ | from | "differ from controls" |
| contribute | to | "contribute to the effect" |

## 3. Word Choice

### 3.1 Affect vs Effect

| Word | Role | Example |
| ---- | ---- | ------- |
| **affect** | verb | "X **affects** Y." |
| **effect** | noun (usually) | "the **effect** of X on Y" |
| **effect** | verb (rare, formal) | "to effect change" |

### 3.2 Fewer vs Less

| Use | Example |
| --- | ------- |
| **fewer** — countable nouns | "fewer studies", "fewer participants" |
| **less** — mass / uncountable | "less evidence", "less time" |

❌ "less studies" → ✅ "fewer studies"
❌ "fewer evidence" → ✅ "less evidence"

### 3.3 Between vs Among

- **between** = two items
- **among** = three or more items

❌ "between the three groups" → ✅ "among the three groups"

### 3.4 Other confusions

| ❌ | ✅ |
| -- | -- |
| comprise of | comprise |
| different than (different kinds) | different from |
| due to (at start of sentence) | owing to / because of |
| in order to | to |
| a number of (with singular noun) | a number of (with plural) |
| the data is | the data are |
| as (for comparisons of dissimilar things) | whereas |
| like (for comparisons) | such as (for examples) |

## 4. Subject-Verb Agreement

### 4.1 With collective nouns

| Subject | Verb | Example |
| ------- | ---- | ------- |
| group | singular (usually) | "the group **was** randomized" |
| participants | plural | "the participants **were** assessed" |

### 4.2 With "data", "media", "criteria"

These are plural in academic English:

- "the **data are**..." (not "data is")
- "the **criteria were**..." (not "criteria was")
- "the **media influence**..." (collective, usually plural in academic writing)

### 4.3 With "each", "every", "either"

Singular verb:
- "**Each** participant **was**..."
- "**Every** measure **shows**..."

## 5. Tense

### 5.1 Common errors

| Context | Tense | Example |
| ------- | ----- | ------- |
| Established knowledge | Present | "**DNA encodes** genetic information." |
| Methods | Past | "We **administered** the PHQ-9." |
| Results | Past | "Scores **decreased** significantly." |
| Discussion of own results | Past | "**CBT reduced** PHQ-9 scores." |
| Discussion of general claim | Present | "This **suggests** that..." |
| Literature review | Present (for claims) | "CBT **is** effective..." |

### 5.2 Tense shifts to avoid

❌ Inconsistent: "We **measured** PHQ-9 scores. The scores **are** lower in the CBT group. **Found** that..."

✅ Consistent past: "We **measured** PHQ-9 scores. The scores **were** lower in the CBT group. We **found** that..."

## 6. Voice (Active vs Passive)

### 6.1 Modern preference: active voice

APA 7, Nature, PLOS — increasingly prefer active:

- ❌ "It was found that CBT reduced symptoms."
- ✅ "We found that CBT reduced symptoms."

### 6.2 When passive is still appropriate

- Methods (when actor is obvious / unimportant): "Samples were centrifuged at 3000 rpm."
- When active would change emphasis: "The participants were randomly assigned..."
- Some traditional fields (older biomedicine): "It is hypothesized that..."

## 7. Sentence Structure Errors

### 7.1 Run-on sentences

❌ "We recruited 100 participants they were aged 12–17 and randomized to CBT or control."

✅ "We recruited 100 participants aged 12–17 and randomized them to CBT or control."

### 7.2 Dangling modifiers

❌ "Having found no significant difference, the study was terminated."

✅ "Having found no significant difference, we terminated the study."

### 7.3 Faulty parallelism

❌ "The study is reliable, valid, and it has been replicated."

✅ "The study is reliable, valid, and replicated."

### 7.4 Misplaced modifiers

❌ "We studied adolescents with depression who were recruited in 2020." (ambiguous: who were recruited, the depression?)

✅ "We studied adolescents with depression, all of whom were recruited in 2020."

## 8. Punctuation

### 8.1 Comma splice

❌ "CBT is effective, we used it in this trial." (two independent clauses joined by comma)

✅ "CBT is effective. We used it in this trial." or "CBT is effective; we used it in this trial."

### 8.2 Comma usage in numbers

- 1,000 (comma as thousands separator)
- 1.5 (period as decimal)
- p < .05 (leading zero dropped per APA 7)
- pp. 23–45 (en-dash for ranges)

### 8.3 Quotation marks

- Use double quotes for short quotations
- Use single quotes inside double quotes: "He called it 'a paradigm shift'."
- For block quotations (40+ words in APA 7), indent and omit quotes

### 8.4 Hyphens, en-dashes, em-dashes

| Symbol | Use |
| ------ | --- |
| Hyphen (-) | Compound adjectives: "well-designed study" |
| En-dash (–) | Ranges: "2015–2020", "pp. 23–45" |
| Em-dash (—) | Punctuation for emphasis: "X—unlike Y—shows..." |

## 9. Citation Style Errors (APA 7)

| ❌ | ✅ |
| -- | -- |
| (Smith, 2020, pp. 23) | (Smith, 2020, p. 23) |
| Smith et al. (2020) when 3+ authors in text | Same — APA 7 uses et al. for 3+ authors (was 6+ in APA 6) |
| DOI as "doi: 10.xxx" | DOI as "https://doi.org/10.xxx" |
| Sentence-case article titles | Title-case article titles in references (APA 7) |
| Hanging indent missing | First line flush left, subsequent lines indented |

## 10. Hedge / Precision Errors

### 10.1 Over-claiming

| ❌ | ✅ |
| -- | -- |
| "proves" (single study) | "suggests" / "indicates" |
| "always" / "never" (without proof) | "typically" / "rarely" / specify conditions |
| "causes" (without experimental design) | "is associated with" / "predicts" |

### 10.2 Under-claiming

| ❌ | ✅ |
| -- | -- |
| "could possibly perhaps" (stacked hedges) | pick one: "may" or "might" |
| "is interesting" (vague praise) | be specific about what's interesting |

### 10.3 Hedge precision

| Strength | Hedge |
| -------- | ----- |
| Definite | demonstrates, shows, establishes |
| Strong | indicates, suggests, supports |
| Moderate | may, appears to, seems to |
| Tentative | possibly, might, could potentially |

## 11. Style Errors (Common ESL)

| Pattern | Issue | Fix |
| ------- | ----- | --- |
| "very" + adj | weak emphasis | delete or use stronger word |
| "more and more" | awkward | increasingly / a growing number |
| "in our country" | Chinglish | specify or delete |
| "with the development of" | Chinglish | delete or restructure |
| "play an important role" | overused | use specific verb |
| "make" + noun | nominalization | use verb form |
| "give suggestions" | not idiomatic | suggest / recommend |

## 12. Verification Checklist

Before finalizing English academic text, check:

- [ ] Article usage correct (a/an/the/zero)?
- [ ] Prepositions idiomatic?
- [ ] Affect vs effect correct?
- [ ] Fewer vs less correct?
- [ ] Subject-verb agreement?
- [ ] Tense consistent within each paragraph?
- [ ] Active vs passive voice appropriate?
- [ ] No comma splices or run-ons?
- [ ] No dangling modifiers?
- [ ] Parallel structure in lists?
- [ ] Citation format correct?
- [ ] Hedge level matches evidence?
- [ ] No "very" or "more and more" or "in our country"?
- [ ] All references have DOIs (for journal articles)?
- [ ] Numbers and units formatted correctly?
