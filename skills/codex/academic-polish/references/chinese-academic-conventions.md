# 中文学术写作规范

本参考为中文学术论文写作提供语体、句式、用词、标点四方面的规范化指引。

## 一、语体（Register）

中文学术写作的总体调性：**客观、严谨、简洁、明确**。避免以下倾向：

| 应避免 | 应改用 |
| ------ | ------ |
| 口语化表达（"我们发现了一个问题"） | 学术化表达（"本文发现"） |
| 感情色彩（"非常有趣的现象"） | 中性描述（"值得注意的现象"） |
| 模糊量词（"很多"、"不少"） | 精确量词（"42 项研究"、"约 67%"） |
| 主观断言（"显然"、"毫无疑问"） | 有据推断（"由此可见"、"本研究推测"） |
| 反问句（"为什么会出现这种现象呢？"） | 陈述句（"该现象的成因可能为..."） |

## 二、句式（Sentence patterns）

### 2.1 主动 vs 被动

中文学术写作**偏主动语态**——这是与英文 IMRAD 的重要差异。

| 场景 | 推荐 |
| ---- | ---- |
| 描述本文工作 | 主动："本文提出了..."、"我们构建了..." |
| 描述客观事实 / 实验结果 | 被动 / 无标记："结果显示..."、"X 被定义为..." |
| 强调方法被应用 | 被动："该方法被应用于..." |
| 描述前人工作 | 主动："Smith 等 (2020) 提出..." |

注意：英文 IMARD 中常见的"We found that..."，中文应避免直译为"我们发现..."——首选"本文发现..."或"研究结果表明..."。

### 2.2 长句与短句

中文学术写作应**长短结合**：

- **长句**（40 字以上）用于表达复杂逻辑关系，适合方法描述、结果分析
- **短句**（15 字以内）用于强调关键发现、过渡到下一论点
- 避免整段都是长句（读者疲劳）或整段都是短句（缺乏论证）

### 2.3 四字结构的恰当使用

中文里适度使用四字结构可提升学术感，但**避免堆砌**：

| 推荐 | 避免 |
| ---- | ---- |
| "系统梳理"、"综合分析"、"实证研究" | 短句里硬塞四字词："本研究通过系统梳理、综合分析、实证研究的方法..." |
| "结果表明"、"基于此"、"由此可见" | "经由上述分析可以明确地发现" |

## 三、用词（Vocabulary）

### 3.1 学术词汇 vs 口语词汇

| 口语 | 学术 |
| ---- | ---- |
| 看看 / 看一下 | 考察 / 审视 / 检验 |
| 觉得 | 认为 / 推测 / 判断 |
| 很重要 / 挺好的 | 具有重要意义 / 表现优异 / 效果显著 |
| 出了问题 | 出现异常 / 存在偏差 / 存在不足 |
| 做了 | 开展 / 实施 / 进行 |
| 用 | 采用 / 使用 / 运用 |
| 发现 | 发现 / 揭示 / 表明（视语境） |

### 3.2 动词的精确性

学术写作应使用**语义精确**的动词：

| 模糊 | 精确 |
| ---- | ---- |
| 研究 | 探讨 / 调查 / 考察 / 实验 / 模拟（视方法选） |
| 分析 | 描述 / 解释 / 评价 / 比较 / 综述 |
| 做 | 开展 / 实施 / 进行 / 构建 / 设计 |
| 弄清 | 阐明 / 揭示 / 厘清 / 厘定 |

### 3.3 名词化倾向的克制

中文比英文更容忍动词化表达；过度名词化反而显得生硬：

| 名词化（避免） | 动词化（推荐） |
| -------------- | -------------- |
| "进行了 X 的分析" | "分析了 X" |
| "对 Y 实施了 Z 的应用" | "应用 Z 于 Y" |
| "对...进行探讨" | "探讨..." |

## 四、标点（Punctuation）

### 4.1 全角 vs 半角

| 场景 | 符号 |
| ---- | ---- |
| 中文正文 | 全角：，。；：？！""''—— |
| 数字 / 英文 / 公式 | 半角：,.;:?!" '- |
| 中英文混排 | 中文字符后用全角，英文 / 数字前后用半角空格分隔 |

### 4.2 常见错误

| 错误 | 修正 |
| ---- | ---- |
| 一段到底没有逗号 | 复合句内部必加逗号断句 |
| 所有并列项都用顿号 | 并列短语用顿号；并列分句用逗号 |
| 引号混乱 | 中文用「」或""，不用'' |
| 英文括号混入中文正文 | 中文正文用全角（） |

## 五、逻辑衔接词

### 5.1 列举 / 顺序

- 首先 / 其次 / 再次 / 最后
- 第一 / 第二 / 第三...
- 一方面 / 另一方面（注意与"首先"搭配时的语义）
- 一是 / 二是 / 三是

### 5.2 递进 / 补充

- 此外 / 另外 / 不仅...而且...
- 更重要的是 / 尤为关键的是
- 在此基础上 / 进一步地

### 5.3 转折 / 让步

- 然而 / 但是 / 不过
- 尽管如此 / 纵使如此
- 与此相反 / 反观 / 反之

### 5.4 因果 / 推断

- 因此 / 因而 / 故
- 由此可见 / 由此推断
- 这表明 / 这意味着 / 提示

### 5.5 总结 / 结论

- 综合以上 / 综上所述
- 本研究表明 / 本研究发现 / 本文的贡献在于

## 六、避免中式英语思维影响中文写作

常见错误：

| 中式英语式中文 | 学术化中文 |
| -------------- | ---------- |
| "在...的领域中" | "在...领域" |
| "进行了...的研究" | "研究了..." |
| "对于...来说是重要的" | "...至关重要" |
| "做出了贡献" | "作出了贡献"（学术语篇偏向"作"） |
| "存在着很多问题" | "存在若干不足" |

## 七、参考文献与引用

- 期刊论文：作者. (年). 文章标题. *期刊名*, *卷*(期), 起页–止页.
- 中文期刊可参考 GB/T 7714—2015
- 西文期刊按 APA 7 格式
- 学位论文按 GB/T 7713.1—2006
