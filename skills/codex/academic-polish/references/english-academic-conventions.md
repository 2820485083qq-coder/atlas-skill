# English Academic Writing Conventions

This reference covers English academic style: hedging, tense, voice, precision, and structural conventions.

## 1. Voice and Person

### 1.1 APA 7 (psychology, education, social sciences)

- **First-person plural "we" is acceptable and often preferred** for clarity ("We found that..." vs. passive "It was found that...").
- Avoid first-person singular "I" except in single-author papers.
- Use "the author(s)" when referring to yourself in third person is rare in APA 7 — prefer "we".

### 1.2 IMRaD / Science (Nature, Science, biomedicine)

- **Passive voice has been the default** but is now actively discouraged in many journals (e.g., Nature, PLOS).
- Active voice is increasingly preferred: "We measured X" rather than "X was measured".
- First-person usage varies by journal — check author guidelines.

### 1.3 Humanities (Chicago, MLA)

- **First-person singular is common** ("I argue", "I read this passage as...").
- Active voice is the norm.

## 2. Tense Usage

| Context | Tense | Example |
| ------- | ----- | ------- |
| Established knowledge | Present | "DNA encodes genetic information." |
| Methods / what you did | Past | "We administered the PHQ-9 at baseline and week 8." |
| Results / what you found | Past | "Mean scores decreased significantly." |
| Discussion of own findings | Past (specific) + Present (general) | "CBT reduced PHQ-9 scores at week 8 (p < .05). This finding suggests..." |
| Referring to prior literature | Present (for claims) / Past (for specific studies) | "CBT is effective for adolescent depression (Smith, 2020). Smith (2020) found that..." |

## 3. Hedging and Claim Strength

Match hedge level to evidence:

| Evidence strength | Hedge / verb | Example |
| ----------------- | ------------ | ------- |
| Highly supported (meta-analysis, replicated) | Direct | "demonstrates", "shows", "establishes" |
| Single study, robust design | Moderate | "suggests", "indicates", "provides evidence for" |
| Pilot, exploratory | Tentative | "appears to", "may", "seems to", "is consistent with" |
| Theoretical / speculative | Speculative | "we speculate", "it is plausible that", "could be interpreted as" |

**Common errors:**
- Under-hedging (over-claiming): "proves" for one study; "always" for a sample
- Over-hedging (timid): "could possibly perhaps be suggested that" — stack too many hedges
- Mismatched hedge and evidence (pilot study presented as definitive)

## 4. Precision

### 4.1 Word choice

| Avoid | Prefer |
| ----- | ------ |
| very / really / quite | remove, or use specific degree |
| a lot of / lots of | many / numerous / a substantial number |
| big / small | large / small, or use specific metric |
| thing / stuff | specific noun |
| show | demonstrate / reveal / indicate / suggest (per evidence) |
| look at | examine / investigate / consider |
| find out | determine / identify / ascertain |
| get better | improve / recover / increase |

### 4.2 Quantifiers

- Use specific numbers: "42 studies", "approximately 67%", "p < .001"
- Avoid vague quantifiers: "many", "some", "often" (use "in 73% of cases" or "in most cases" only if grounded)

### 4.3 Nominalization

Reduce excessive nominalization:

| Nominalized (avoid) | Verbal (prefer) |
| ------------------- | --------------- |
| "performed an analysis of" | "analyzed" |
| "conducted an investigation into" | "investigated" |
| "made the decision to" | "decided to" |
| "is in agreement with" | "agrees with" |

## 5. Sentence Structure

### 5.1 Length

- Aim for 15–25 words per sentence on average
- Vary length: short sentences for emphasis, long for complex relationships
- Avoid > 40 words without internal punctuation

### 5.2 Parallel structure

Use parallel grammar in lists:

- ❌ "The study is reliable, valid, and it has been replicated."
- ✅ "The study is reliable, valid, and replicated."
- ❌ "We measured X, Y was tested, and we also looked at Z."
- ✅ "We measured X, tested Y, and examined Z."

### 5.3 Topic sentences

Every paragraph should open with a clear topic sentence stating the paragraph's main claim or function.

### 5.4 Transitions

Use explicit transitions between paragraphs and ideas:

- Addition: furthermore, moreover, in addition
- Contrast: however, nevertheless, in contrast
- Cause: therefore, consequently, as a result
- Example: for instance, specifically, in particular
- Sequence: subsequently, then, following this

## 6. Articles (a / an / the / zero)

| Rule | Example |
| ---- | ------- |
| Use "the" for specific referent | "**The** study by Smith (2020)..." |
| Zero article for generalizations | "**Ø** Depression is common in adolescents." |
| "a/an" for first mention, nonspecific | "**A** recent meta-analysis found..." |
| "the" for second mention | "Smith (2020) found X. **The** finding..." |

**Common Chinglish article errors:**
- ❌ "The depression is common." → ✅ "Depression is common."
- ❌ "We conducted a study about the effect of X on Y." → ✅ "We studied the effect of X on Y." (or "We conducted a study of the effect...")

## 7. Prepositions

Common confusions:

| ❌ | ✅ |
| -- | -- |
| discuss about | discuss |
| research on | research into / research on (both OK; research into is more idiomatic) |
| focus on (verb) | focus on |
| in the basis of | on the basis of |
| despite of | despite (no "of") |
| according to (NOT "according with") | according to |
| in regards to | in regard to / with regard to / regarding |
| compared with vs compared to | with = similar items; to = dissimilar items |

## 8. Numbers and Units

- Spell out one through nine; use digits for 10+
- Always use digits with units: "5 mg", not "five mg"
- Use digits for statistics: "p < .05", "n = 42", "M = 23.4"
- APA 7 uses leading zero: "p < .05" (not "p < 0.05") for values that cannot exceed 1.0
- Use en-dash (–) for ranges, not hyphen: "pp. 23–45", "2015–2020"

## 9. Citation Style Quick Reference (APA 7)

| Type | Format |
| ---- | ------ |
| Journal article | Author, A. A., & Author, B. B. (Year). Title of article. *Journal Name*, *Volume*(Issue), pages. https://doi.org/xxx |
| Book | Author, A. A. (Year). *Title of book*. Publisher. |
| Chapter in edited book | Author, A. A. (Year). Title of chapter. In E. E. Editor (Ed.), *Title of book* (pp. xx–xx). Publisher. |
| In-text | (Author, Year) or (Author, Year, p. xx) |
| Three+ authors | First author et al. — (Smith et al., 2020) |

## 10. Common Style Errors to Fix

- "data is" → "data are" (data is plural)
- "less" (countable) → "fewer" (countable); "less" for mass quantities
- "between" (two) / "among" (three or more)
- "affect" (verb) / "effect" (noun usually; verb rare)
- "comprise" = include (the whole comprises the parts); NOT "comprise of"
- "different from" (NOT "different than")
- "as" for comparisons of similarity: "as ... as"; "like" for examples, not comparisons
