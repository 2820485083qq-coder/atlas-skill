# Skill 路由

根据目标产物、输入材料与验收方式选择最小适用 Skill 集合。当前会话可见的 Skill 和工具是可用性依据；历史路由图只供参考。

单一专业 Skill 能完成请求时直接交给它；没有适用 Skill 时直接处理。用户指定产物和流程优先，按需增加内容、格式或验证支持，不把可选流程变成前置条件。

只在选择仍不明确时读取对应参考：
- 一般领域选择：[skill-map.md](references/skill-map.md)。
- 用户要求 Matt Pocock 工作流或需要区分其工程入口：[matt-pocock-routing.md](references/matt-pocock-routing.md)。
- 学术写作 Skill 重叠：[research-writing-routing.md](references/research-writing-routing.md)。
- 代码任务需要行为约定：[coding-agent-routing.md](references/coding-agent-routing.md)。

从参考中选择当前分支，核验入口确实可用后完整阅读选中 SKILL.md。相同职责的 Skill 选择一个主入口；参考中的固定长链仅在任务确实需要时采用。不得因路由文档提及某 Skill 就自动加载它或初始化项目。

路由完成意味着当前产物、主 Skill 和必要验证已明确，随后执行到用户请求完成。只报告实际使用的 Skill；路由本身不是交付物，除非用户只要求选型。
