## Framework Selection

| User Need | Framework | Best For |
| --- | --- | --- |
| Executive-facing answer, report, recommendation | Pyramid Principle | Conclusion-first communication |
| Explaining why a proposal matters | SCQA | Situation -> Complication -> Question -> Answer |
| Describing experience, achievement, interview answer | STAR | Situation -> Task -> Action -> Result |
| Work daily/weekly report | Work report structure | Progress, results, risks, next plan |
| Long messy text needs short version | Summary structure | Key points, decisions, risks |
| Text needs expansion but facts must stay stable | Controlled expansion | Add context, examples, transitions |

Use one primary framework unless the user asks for alternatives.

## Operating Principles

- Identify the audience first: self, supervisor, committee, reviewer, public reader, or future self.
- Put conclusions before details when the reader is busy or decision-oriented.
- Preserve facts, numbers, dates, names, citations, and uncertainty.
- Do not turn weak evidence into confident claims.
- Remove filler, but do not remove necessary caveats.
- For Chinese reports, prefer clear professional prose over ornate phrasing.

## Output Patterns

### Pyramid Principle

```markdown
## 结论

## 支撑理由

1. 
2. 
3. 

## 证据

## 风险/例外

## 下一步
```

Check MECE: support points should not heavily overlap, and the main necessary reasons should not be missing.

### SCQA

```markdown
## S 情境

## C 冲突/复杂化

## Q 核心问题

## A 答案/方案
```

The complication should be concrete, not artificial drama.

### STAR

```markdown
## Situation 背景

## Task 任务

## Action 行动

## Result 结果
```

Results should include measurable outcomes when available. If no metric exists, state observable impact.

### Weekly Report

```markdown
# 周报

## 本周核心成果

## 重点工作进展

## 问题与风险

## 下周计划

## 需协调事项
```

Avoid activity logs. Convert "参加会议/写文档/沟通" into outcome language only when the outcome is real.

### Summary

```markdown
## 一句话结论

## 关键要点

## 决策/行动项

## 风险与未决问题
```

## Expansion Rules

When expanding content:

- Preserve original meaning and tone.
- Add only plausible context that follows from the source.
- If required information is missing, mark a placeholder or ask briefly.
- Do not inflate with generic sentences.
