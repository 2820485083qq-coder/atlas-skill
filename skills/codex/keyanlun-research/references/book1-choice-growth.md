# Book 1: Choice and Growth

Use this reference for layer diagnosis, advisor/path choice, focus recovery, graduation-path planning, and mindset/interpersonal blocks that prevent research action.

## Source Scope

Distilled from the `《科研论1：选择与成长篇》` section of the Keyanlun column index, the homepage layer table, and the pinned "start here" article. The public index maps this book around: target audience, matching resources to current status, advisor information search, key information extraction, statistical comparison, end-in-mind planning, and modular tools for focus, research-paper production, literature-reading misconceptions, exam-oriented thinking, relationships, and mental recovery.

## Core Model

Book 1 is the entry controller. It asks:

1. What future option is the user trying to preserve or open?
2. What layer are they actually in?
3. What output would make the next decision less vague?
4. Is the user solving the real problem, or only the first problem that appeared in their head?

Do not let the user start with "I should read more" or "I should work harder" until the target output is named.

## Chapter-Level Method Cards

### Card 1: 对号入座

Use when the user arrives with a vague research/life complaint.

Method:

1. Identify whether the problem is choice, production, graduation, relationship/mental state, or young-faculty/project pressure.
2. Map the user to a layer before recommending any resource.
3. Name the output that would move them to the next layer.
4. Ignore resources from later layers until the current blocking layer is handled.

Deliverable:

- Layer diagnosis.
- Output target.
- Resource route.
- One action the user can do today.

### Card 2: 搜集导师信息

Use when selecting an advisor, postdoc group, doctoral destination, or collaborator.

Method:

1. Start with a candidate advisor or lab list.
2. Gather publication and student-output evidence instead of relying on profile text.
3. Separate advisor-led papers, student-led papers, multi-corresponding-author papers, collaborations, and recent continuity.
4. Estimate whether students can graduate with the user's desired future options.
5. Look for mismatch between "projects look abundant" and "students actually produce usable outputs."

Deliverable:

| Candidate | Recent Papers | Student First-Author Output | Typical Graduation Evidence | Direction Fit | Resource/Platform | Risk Signal | Next Check |
| --- | --- | --- | --- | --- | --- | --- | --- |

Risk signals:

- Recent cohorts have few student-led papers.
- Most outputs depend on outside collaborators.
- Advisor has many projects but unclear student training path.
- Direction is fashionable but not connected to the user's graduation requirements.

### Card 3: 以终为始

Use when the user asks "which choice is better" without defining better for what.

Method:

1. Define target after graduation: industry, PhD, postdoc, faculty, overseas path, stable job, entrepreneurship, or safe graduation.
2. Translate that target into current evidence requirements.
3. Rank choices by preserving future options, not by immediate prestige alone.
4. Prefer fuzzy correctness over precise wrongness: avoid big pits first, then optimize.

Deliverable:

- Future-option matrix.
- Candidate ranking.
- "Must avoid" list.
- Minimum acceptable choice.

### Card 4: 已做选择后的快速止损

Use when the user is already in a group or direction and regrets it.

Method:

1. Do not spend energy only proving the choice was bad.
2. Identify graduation conditions and available outputs.
3. Map the current state into the five-step loop.
4. If environment cannot be changed, find the shortest path to a paper/dissertation output or a better next platform.

Deliverable:

- Current constraints.
- Output path.
- Environment risks.
- What to stop doing.
- What to do next.

## Layer and Choice Workflow

### 0. Recover Focus

Use when the user is emotionally blocked, distracted by relationships, or unable to act.

Output:

- One concrete action that returns them to a research layer.
- A short note distinguishing solvable research work from emotional/interpersonal noise.
- A recommendation to avoid major choices while dysregulated unless deadlines force action.

### 1. Choose With Evidence

Use when choosing an advisor, degree path, research direction, postdoc, job route, or whether to continue.

Output:

- End-state criteria: graduation, papers, training, career optionality, geography, health, family, money, or independence.
- Evidence table, not vibes.
- Risk list: graduation risk, authorship risk, resource risk, communication risk, direction risk.
- Minimum next move: gather advisor/lab outputs, student outcomes, publication patterns, funding/project context, and graduation requirements.

### 2. Re-enter Research Production

If the user is already in a group and cannot change the environment easily, shift from "what should I have chosen" to "what can still open options now."

Output:

- Current graduation constraints.
- Small-paper or dissertation output target.
- Which layer blocks that target: 2.1/2.2/2.3/3/4.

## Evidence Table: Advisor/Path Choice

Use this table when the user asks for a concrete template.

| Dimension | What to Collect | Why It Matters |
| --- | --- | --- |
| Graduation requirement | School/department paper and defense rules | Defines the minimum viable output |
| Student output | First-author or equivalent papers by recent students | Shows whether the lab reliably trains students to graduate |
| Time-to-output | Years from enrollment to first paper/degree | Reveals hidden delay risk |
| Advisor role | Corresponding author pattern, collaboration network | Distinguishes advisor's own training capacity from borrowed output |
| Direction continuity | Whether recent papers cluster around stable themes | Shows whether the student can accumulate rather than restart |
| Resource match | Data, equipment, samples, code, field access, funding | Determines whether the route is actually executable |
| Future option | Past students' PhD/job/faculty/postdoc paths | Tests whether the choice opens the intended door |
| Human risk | Communication, authorship, power structure, emotional safety | Prevents "good paper but bad life" traps |

## Common Misroutes

- The user asks how to read papers, but the real issue is advisor/direction choice.
- The user asks whether they are "suitable for research", but the answer needs evidence about environment, constraints, and output path.
- The user wants a perfect life decision; ask for a robust enough decision that avoids major pits and preserves future options.
- The user treats mental discomfort as proof they cannot continue; first separate emotional state from production constraints.
