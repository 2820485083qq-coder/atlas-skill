# Book 5: Neural-Network-Led Writing

Use this reference when the user has a verified idea, research materials, data/results, or a draft and needs to write, diagnose, or revise a research paper.

## Source Scope

Distilled from the `《科研论5：神经网络主导的写作》` section of the Keyanlun column index, the `《科学研究与论文写作》` writing-related index, the homepage "overall framework and outputs" section, and the five-step article's `合` explanation. The index emphasizes text material libraries, introduction writing, sentence-level comparison, tagging/summarizing examples, material-library generation, fact/opinion/logic separation, and checklist-based revision.

## Core Model

Writing is not a final typing phase. It is the visible form of whether the idea, verification, and material libraries are coherent.

The main unit is the material library, not the blank page.

Use three libraries together:

- Hard-material library: figures, data, tables, formulas, code, mechanisms, screenshots, protocols, or other non-text evidence.
- Introduction text library: how the field frames the background, problem, gap, and significance.
- Results/discussion text library: how comparable evidence is interpreted.

## Chapter-Level Method Cards

### Card 1: 左右分屏文字素材库

Do not begin from a blank page. Put source examples on one side and the user's draft or sentence plan on the other side.

Use the material library to learn sentence functions:

- What job does this sentence do?
- What information does it include?
- What order does it use?
- What citation or evidence supports it?
- What can be replaced by the user's object, method, result, or mechanism?

Output:

- Same-function example set.
- Sentence-function notes.
- User-specific sentence candidates.

### Card 2: 标签化

After collecting introduction or discussion examples, summarize each example with a short functional label. Tags should describe the move, not only the topic.

Useful tags:

- Field importance.
- Practical demand.
- Existing limitation.
- Method gap.
- Material/object gap.
- Mechanism gap.
- Contribution preview.
- Result comparison.
- Mechanism interpretation.
- Limitation/future work.

Twenty to thirty high-quality examples can be enough for a focused writing task if they are strongly matched to the rhetorical function.

### Card 3: 比大小法 / 功能对比

Compare examples with the same function before imitating them.

Ask:

- Which example is more suitable for this paper's level and target journal?
- Which one uses a stronger evidence chain?
- Which one has a clearer gap statement?
- Which one overclaims relative to the user's evidence?

Then compose by adapting the stronger pattern to the user's actual material.

### Card 4: 从文献库到素材库

The literature library is broad; the writing material library is selective. Move papers from the corpus into a text library only when they help write a specific paragraph, sentence job, figure interpretation, or discussion comparison.

Preserve links back to the original paper, group, and evidence so writing does not become detached from provenance.

### Card 5: 论文不像论文的诊断

If the draft reads like a dissertation summary, diagnosis comes before language polish.

Check:

- Does the paper have one central scientific question?
- Are the figures and tables arranged to answer that question?
- Is the introduction built from a gap, not a topic encyclopedia?
- Is the discussion comparing and interpreting evidence, not repeating results?
- Does every major claim have hard material or literature support?

## Writing Workflow

### 1. Diagnose Before Polishing

Ask:

- What is the paper's focused scientific question?
- What evidence answers it?
- Which figures/tables/data are central?
- Which paragraph or sentence currently has no material support?
- Is this a research paper or a compressed dissertation?

If the question/evidence chain is weak, route back to Book 3 or Book 4.

### 2. Build the Text Material Library

Actions:

- Select papers that solve a similar rhetorical task, not only papers with the same topic.
- Split examples by function: background, gap, method, object, result, limitation, mechanism, implication.
- Tag or summarize each example by what it does in the argument.
- Preserve citation provenance so generated sentences do not detach from sources.

Output:

- Material-library table.
- Functional tags.
- Candidate sentence moves.

### 3. Compose by Function and Comparison

Instead of asking "how do I write a beautiful sentence", ask "what job must this sentence do?"

Common sentence jobs:

- Establish field importance.
- Narrow from broad field to specific object.
- State known limitation.
- Identify gap.
- Introduce method or material.
- Explain why this route matters.
- Preview contribution.

Use comparison:

- Compare same-function examples.
- Identify shared elements.
- Replace object/method/context with the user's own materials.
- Check whether the sentence still matches the paper's actual evidence.

### 4. Align Material, Experiment, and Writing

For each claim, identify its support:

- Figure/table/data/formula/code/protocol.
- Literature support.
- Logic step.
- Limitation or caveat.

If a claim has no support, remove it or produce the missing material.

### 5. Revise With Checklist

Check:

- Scientific question is explicit.
- Paper is not a dissertation summary.
- Each section serves the central question.
- Facts, opinions, and logic are separated.
- References support the exact claims they are attached to.
- Figures and tables are necessary and interpretable.
- Discussion expands horizontally and vertically: compare across studies and dig into mechanisms/limitations.
- Similar-paper risk, authorship, journal fit, ethics, and submission constraints are addressed.

## Common Mistakes

- Asking for language polish when the scientific question is not focused.
- Writing introduction from memory instead of from a text material library.
- Using only a few examples and overgeneralizing.
- Losing citation provenance while recombining sentences.
- Letting dissertation structure dictate paper structure.
- Writing first, then discovering the experiment or idea is flawed.
